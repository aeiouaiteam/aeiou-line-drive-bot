````text
ช่วยติดตั้ง "บอท LINE ↔ Google Drive" ให้ฉันตั้งแต่ต้นจนใช้งานได้จริง แล้วทดสอบให้ผ่านครบทุกขั้น

# บอทนี้คืออะไร
โค้ดอยู่ที่ https://github.com/aeiouaiteam/aeiou-line-drive-bot
ให้ดึงโค้ดมาแล้วอ่าน README.md และ server.js ให้เข้าใจก่อนเริ่มขั้นอื่น
บอทตัวเดียวทำ 2 อย่างให้ LINE Official Account (OA) ของฉัน
A) จด: ทุกข้อความในกลุ่ม LINE ที่ OA อยู่ ถูกบันทึกลง Google Drive โฟลเดอร์ "Note from LINE"

# เกี่ยวกับฉัน และวิธีทำงานที่ต้องการ
- ฉันไม่มีพื้นฐานเทคนิค คุยกับฉันเป็นภาษาไทยแบบภาษาคน ทุกครั้งที่ต้องให้ฉันทำอะไร ให้บอกทีละอย่าง สั้น ๆ ว่ากดอะไรตรงไหน แล้วรอฉันบอกว่าเสร็จ
- ทำเองให้มากที่สุด ทั้งคำสั่งในเครื่องและการกดในเบราว์เซอร์ ถ้ามีเครื่องมือควบคุมเบราว์เซอร์ให้ใช้เปิดหน้าและกดตั้งค่าให้ ถ้าไม่มี ให้บอกฉันทีละคลิก
- ทำทีละขั้นตามลำดับ แต่ละขั้นมีข้อ "ผ่านเมื่อ" ต้องตรวจให้ผ่านจริงก่อนไปขั้นถัดไป ถ้าไม่ผ่าน ให้หาสาเหตุและแก้ก่อน (ดูหัวข้อ "ถ้าติดปัญหา") อย่าข้าม และอย่าบอกว่าเสร็จถ้ายังไม่ได้ตรวจ
- เว็บพวกนี้เปลี่ยนหน้าตาและชื่อเมนูบ่อย ถ้าหน้าจอไม่ตรงกับที่เขียนไว้ ให้ดูหน้าจอจริงแล้วหาทางที่ให้ผลเดียวกัน
- เริ่มงานด้วยการถามฉัน 3 ข้อ แล้วค่อยลงมือ:
  (1) จะใช้บัญชี Google ไหน แนะนำบัญชีแยกสำหรับระบบนี้ เพราะบอทจะอ่านไฟล์ใน Google Drive ของบัญชีนั้นได้ทั้งหมด
  (2) มีบัญชี Railway แล้วหรือยัง
  (3) จะสร้าง LINE OA ใหม่ชื่ออะไร หรือจะใช้ OA ที่มีอยู่

# สิ่งที่ฉันอนุญาตให้ทำได้เลยโดยไม่ต้องถามซ้ำ
- ติดตั้งโปรแกรมที่จำเป็นในเครื่อง: git, Node.js, Railway CLI
- สร้างและตั้งค่า LINE OA ตามขั้นที่ 2, โปรเจกต์ Google Cloud ชื่อ line-drive-bot ตามขั้นที่ 3, โปรเจกต์ Railway ชื่อ line-drive-bot ตามขั้นที่ 4
- ตั้ง Webhook ของ LINE และตั้งค่าตัวแปรของบอทบน Railway

# สิ่งที่ต้องหยุดให้ฉันทำเองเสมอ
- ล็อกอินทุกเว็บ และใส่รหัสยืนยันตัวตน (ห้ามขอรหัสผ่านจากฉัน)
- ใส่ข้อมูลบัตรเครดิต และกดยืนยันการสมัครแพ็กเกจที่เสียเงิน (บอกราคาให้ฉันทราบก่อน)
- กดยอมรับข้อตกลงการใช้งาน และกด "อนุญาต" ให้บอทเข้าถึง Google Drive
- การส่งข้อความจริงเข้ากลุ่ม LINE ครั้งแรก (ขั้นที่ 7) ต้องบอกฉันและรอฉันตกลงก่อน

# รหัสลับ
Channel secret, Client secret, refresh token และ ADMIN_KEY เป็นรหัสลับ
- ให้ฉันคัดลอกจากหน้าเว็บมาวางในแชท แล้วคุณใส่เข้า Railway ผ่านคำสั่งเท่านั้น
- อย่าพิมพ์ทวนรหัสลับกลับมาในแชท อย่าเขียนลงไฟล์ใด ๆ ในโฟลเดอร์โค้ด และอย่าใส่ใน URL

# ขั้นตอน

## ขั้นที่ 1: เตรียมเครื่อง
- ตรวจว่ามี git และ Node.js 18 ขึ้นไป ถ้าไม่มีให้ติดตั้ง (Windows: winget install OpenJS.NodeJS.LTS และ Git.Git / Mac: Homebrew หรือตัวติดตั้งจาก nodejs.org)
- ติดตั้ง Railway CLI: npm install -g @railway/cli
- ดึงโค้ดไว้ในโฟลเดอร์ที่ฉันทำงานอยู่: git clone https://github.com/aeiouaiteam/aeiou-line-drive-bot แล้วรัน npm install ในโฟลเดอร์นั้น
ผ่านเมื่อ: node --version และ railway --version ทำงานได้ และในโฟลเดอร์โค้ดมี node_modules

## ขั้นที่ 2: LINE Official Account
ที่ https://manager.line.biz (ฉันล็อกอินเอง)
- สร้าง OA ใหม่ตามชื่อที่ฉันบอก (หรือเปิด OA เดิมที่ฉันเลือก)
- ตั้งค่า → Messaging API → กดเปิดใช้ Messaging API แล้วเลือกหรือสร้าง Provider
- ตั้งค่า → ตั้งค่าบัญชี → หัวข้อการเข้าร่วมแชท → เลือก "อนุญาตให้เข้าร่วมกลุ่มหรือแชทแบบหลายคน"
- ตั้งค่า → การตั้งค่าการตอบกลับ → ปิดแชท, ปิดข้อความตอบกลับอัตโนมัติ, เปิด Webhook (บอทนี้ต้องเงียบ ไม่ตอบใคร)
ที่ https://developers.line.biz/console/ → เลือก Provider → เลือก channel ของ OA นี้ → แท็บ Basic settings
- ให้ฉันคัดลอก Channel ID และ Channel secret มาวางในแชท (ไม่ต้องออก Channel access token บอทขอเองได้จากสองค่านี้)
ผ่านเมื่อ: ส่ง POST ไป https://api.line.me/oauth2/v3/token ด้วย grant_type=client_credentials, client_id=Channel ID, client_secret=Channel secret แล้วได้ access_token และใช้ token นั้นเรียก GET https://api.line.me/v2/bot/info ได้ชื่อ OA ตรงกับของฉัน

## ขั้นที่ 3: Google Cloud (ออกบัตรผ่านให้บอทเข้า Google Drive ไม่มีค่าใช้จ่ายและไม่ต้องผูกบัตร)
ที่ https://console.cloud.google.com ด้วยบัญชี Google ที่ฉันเลือก (ฉันล็อกอินและยอมรับข้อตกลงเอง)
- สร้างโปรเจกต์ใหม่ชื่อ line-drive-bot และตรวจว่ากำลังเลือกโปรเจกต์นี้อยู่ก่อนทำข้อถัดไปทุกข้อ
- APIs & Services → Library → ค้น "Google Drive API" → Enable
- เมนู Google Auth Platform (ชื่อเดิม OAuth consent screen) → Get started: ชื่อแอป "LINE Drive Bot", อีเมลของฉัน, Audience เลือก External, ใส่อีเมลติดต่อ, ยอมรับนโยบาย แล้ว Create
- Google Auth Platform → Audience → กด Publish app ให้สถานะเป็น In production
  ข้อนี้สำคัญมาก: ถ้าสถานะยังเป็น Testing บอทจะหลุดสิทธิ์ทุก 7 วัน ไม่ต้องส่งแอปให้ Google ตรวจ (verification) เพราะฉันใช้คนเดียว
- Google Auth Platform → Clients → Create client → Application type เลือก "Desktop app" → Create
- ให้ฉันคัดลอก Client ID และ Client secret มาวางในแชท
จากนั้นในโฟลเดอร์โค้ด ให้รันคำสั่งนี้แบบเบื้องหลังแล้วรอจนจบ:
  node scripts/google-login.js <client_id> <client_secret>
- คำสั่งจะเปิดเบราว์เซอร์ไปหน้า Google ให้ฉันกดอนุญาต ก่อนรัน ให้บอกฉันล่วงหน้าว่า:
  (1) เลือกบัญชี Google เดียวกับที่ใช้ในขั้นนี้
  (2) จะเจอหน้าเตือน "Google hasn't verified this app" ให้กด Advanced แล้วกด Go to LINE Drive Bot (เป็นแอปของฉันเอง)
  (3) ต้องติ๊กอนุญาตให้ครบทุกข้อ แล้วกด Continue
ผ่านเมื่อ: คำสั่งพิมพ์ "OK - saved" และมีไฟล์ .secrets/google.json (โฟลเดอร์นี้ไม่ถูกอัปโหลดขึ้นที่ใด)

## ขั้นที่ 4: Railway (ที่ให้บอททำงานตลอด 24 ชั่วโมง)
- ถ้าฉันยังไม่มีบัญชี พาไปสมัครที่ https://railway.com
  แนะนำแพ็กเกจ Hobby (ประมาณ 5 ดอลลาร์สหรัฐต่อเดือน รวมค่าใช้งานของบอทตัวนี้แล้ว) ให้ตรวจราคาปัจจุบันจากหน้าเว็บแล้วบอกฉันก่อน ฉันใส่บัตรและกดยืนยันเอง
  บัญชีทดลองฟรีอาจใช้ได้ชั่วคราว แต่ถ้าขึ้นระบบไม่ได้ หรือบอทต่อ LINE/Google ไม่ได้ ให้แนะนำอัปเกรดเป็น Hobby
- ล็อกอิน CLI: รัน railway login --browserless แบบเบื้องหลัง แล้วส่งลิงก์ยืนยันที่คำสั่งพิมพ์ออกมาให้ฉันกด รอจนคำสั่งจบ แล้วตรวจด้วย railway whoami
- ในโฟลเดอร์โค้ด:
  railway init --name line-drive-bot
  railway add --service bot        (ถ้าคำสั่งรอถามค่าตัวแปร ให้ส่ง input ว่างเพื่อข้าม)
- สร้าง ADMIN_KEY เป็นตัวอักษรและตัวเลขสุ่มอย่างน้อย 32 ตัว
- ตั้งค่าตัวแปร 6 ตัวด้วย railway variables --service bot --skip-deploys --set "ชื่อ=ค่า":
  LINE_CHANNEL_ID, LINE_CHANNEL_SECRET, GOOGLE_OAUTH_CLIENT_ID, GOOGLE_OAUTH_CLIENT_SECRET, GOOGLE_OAUTH_REFRESH_TOKEN (สามค่าหลังอ่านจาก .secrets/google.json), ADMIN_KEY
  แล้วตรวจด้วย railway variables --service bot --kv ว่ามีครบ 6 ชื่อ (ดูเฉพาะชื่อ อย่าแสดงค่า)
- ขึ้นระบบ: railway up --service bot --ci
- สร้างที่อยู่เว็บ: railway domain --service bot แล้วจดที่อยู่ไว้ (ต่อไปเรียกว่า <เว็บบอท>)
- ลบโฟลเดอร์ .secrets ทิ้ง
- ห้ามเพิ่มจำนวน replica และห้ามเปิด Serverless / App Sleeping ให้บริการนี้ เพราะบอทต้องตื่นตลอดเพื่อเช็กไฟล์ทุกนาที
ข้อควรระวังบน Windows:
- ถ้ารันผ่าน Git Bash ให้ตั้ง MSYS_NO_PATHCONV=1 ก่อน ไม่อย่างนั้นค่าที่ขึ้นต้นด้วย / จะถูกแปลงเป็นพาธของเครื่อง
- ค่าที่เป็น JSON (ตัวแปร MENTIONS ในขั้นที่ 8) มักถูกตัดเครื่องหมาย " ทิ้งเมื่อเรียกผ่าน railway.cmd ให้เรียกไฟล์ railway.exe ตรง ๆ (อยู่ในโฟลเดอร์ npm global: node_modules/@railway/cli/bin/) และตรวจค่าหลังตั้งทุกครั้ง
- ถ้าคำสั่ง railway ตัวไหนใช้ไม่ได้ตามที่เขียนไว้ ให้ดู railway <คำสั่ง> --help ของเวอร์ชันที่ติดตั้งจริง
ผ่านเมื่อ: เปิด https://<เว็บบอท>/ แล้วได้ข้อความว่าบอททำงานอยู่ และเรียก https://<เว็บบอท>/check โดยส่ง ADMIN_KEY ใน header X-Admin-Key แล้วได้ line.ok เป็น true (ชื่อ OA ถูกต้อง) และ drive.ok เป็น true พร้อมลิงก์โฟลเดอร์ 2 อัน
- ส่งลิงก์โฟลเดอร์ทั้งสองให้ฉันเปิดดูว่ามี "Note from LINE" และ "Comment from Dots" ใน Google Drive แล้ว และบอกฉันว่าย้ายหรือเปลี่ยนชื่อโฟลเดอร์ภายหลังได้ แต่ห้ามลบแล้วสร้างใหม่เอง

## ขั้นที่ 5: ต่อ LINE เข้ากับบอท
ที่ LINE Developers → channel นี้ → แท็บ Messaging API → หัวข้อ Webhook settings
- Webhook URL ใส่ https://<เว็บบอท>/webhook → Update → กด Verify → เปิด Use webhook
ผ่านเมื่อ: Verify ขึ้น Success และ Use webhook เปิดอยู่

## ขั้นที่ 6: ทดสอบการจด (LINE → Drive)
- ให้ฉันเชิญ OA เข้ากลุ่ม LINE ที่ต้องการ (ถ้ายังไม่มี ให้สร้างกลุ่มทดสอบ) แล้วพิมพ์ 2–3 ข้อความในกลุ่ม
- รอ 30 วินาที แล้วเรียก https://<เว็บบอท>/groups (ส่ง ADMIN_KEY ใน header)
ผ่านเมื่อ: /groups แสดงกลุ่มนั้นพร้อมชื่อฉันในรายชื่อสมาชิก และใน "Note from LINE" มีโฟลเดอร์ชื่อกลุ่ม ข้างในมีไฟล์ chat-log-ปี-เดือน.txt ที่มีข้อความที่ฉันพิมพ์ (ให้ฉันเปิดดูเอง)
- ถามฉันว่าจะให้บอทส่งข้อความเข้ากลุ่มไหน แสดงชื่อกลุ่มจาก /groups ให้เลือก แล้วตั้งตัวแปร TARGET_GROUP_ID เป็นรหัสกลุ่มนั้น (ครั้งนี้ไม่ใส่ --skip-deploys เพื่อให้บอทเริ่มใหม่) รอจนบอทกลับมาแล้วตรวจที่ /check ว่า sending.on เป็น true และ sending.groupName ตรงกับกลุ่มที่ฉันเลือก

## ขั้นที่ 7: ทดสอบการส่ง (Drive → LINE)
- บอกฉันว่าขั้นนี้จะมีข้อความจริงเข้ากลุ่ม 1 ข้อความ และรอฉันตกลงก่อน
- หาวันที่และเวลาปัจจุบันของประเทศไทย (UTC+7) แล้วให้ฉันสร้าง Google Docs 1 ไฟล์ในโฟลเดอร์ "Comment from Dots" โดยคุณพิมพ์ชื่อไฟล์ให้ฉันคัดลอกไปวาง รูปแบบ:
  2026-12-01 14.30 — ทดสอบ
  (ปี-เดือน-วัน เว้นวรรค ชั่วโมง.นาที เว้นวรรค ขีด เว้นวรรค ชื่อเรื่อง) แล้วให้ฉันพิมพ์ข้อความสั้น ๆ ในไฟล์
- บอทรอ 1 นาทีหลังไฟล์ถูกแก้ล่าสุดแล้วจึงส่ง ให้รอ 2 นาทีแล้วตรวจ ถ้าตอนนั้นอยู่นอกเวลาส่งของบอท (ค่าเริ่มต้นคือ 07:00–20:59 ทุกวัน) ให้เรียก https://<เว็บบอท>/run แทน
ผ่านเมื่อ: ฉันยืนยันว่าข้อความขึ้นในกลุ่ม LINE และ /check แสดงไฟล์นั้นสถานะ sent
- เรียก /run ซ้ำอีก 1 ครั้ง เพื่อยืนยันว่าบอทไม่ส่งไฟล์เดิมซ้ำ

## ขั้นที่ 8: ตั้งค่าเพิ่ม (ถามฉันทีละข้อ ข้อไหนฉันไม่เอาให้ข้าม)
- เวลาส่ง: ค่าเริ่มต้นคือทุกวัน 07:00–20:59 ถ้าฉันต้องการแบบอื่น ตั้งตัวแปร SCHEDULE เช่น 1-5=9-18 คือจันทร์–ศุกร์ 09:00–18:59 (0 = อาทิตย์, คั่นหลายช่วงด้วยจุลภาค)

## ขั้นที่ 9: เตรียมคำสั่งให้ผู้ช่วย AI (Dots)
- เปิดไฟล์ docs/dots-prompt.md ถามฉันเพื่อเติมช่อง [ ] ให้ครบ: ชื่อผู้ช่วย, ชื่อทีม, รายชื่อคนในทีมและหน้าที่, เวลารอบเช้าและรอบเย็น, ชื่อเล่นที่แท็กได้ (ให้ตรงกับ MENTIONS) และช่วงเวลาในชื่อไฟล์ (ให้ตรงกับ SCHEDULE)
- บันทึกฉบับที่เติมแล้วเป็นไฟล์ "คำสั่งสำหรับ Dots.md" ในโฟลเดอร์โค้ด และแสดงให้ฉันคัดลอก
- บอกฉันว่าต้องนำไปตั้งในผู้ช่วย AI ที่ (1) ต่อ Google Drive บัญชีเดียวกับที่บอทใช้ (2) สร้างและเปลี่ยนชื่อ Google Docs ได้ (3) ตั้งให้ทำงานตามเวลาได้ ส่วนนี้ฉันไปตั้งเองในแอปของผู้ช่วย

## ขั้นที่ 10: ส่งมอบ
- สรุปให้ฉันเป็นภาษาคน: OA ชื่ออะไร, บอทอยู่ที่ไหน, ลิงก์โฟลเดอร์ Drive สองอัน, กลุ่มที่ส่งเข้า, เวลาที่ส่ง, ชื่อที่แท็กได้, ค่าใช้จ่ายรายเดือน
- ตารางผลตรวจขั้นที่ 1–9 ว่าผ่านหรือไม่ผ่าน ข้อไหนไม่ได้ทำหรือไม่ผ่าน ให้บอกตรง ๆ
- วิธีใช้งานประจำวัน: กติกาชื่อไฟล์ (DRAFT ระหว่างเขียน → เปลี่ยนชื่อเป็นรูปแบบพร้อมส่ง), เส้น --- แยกกล่องแชท, [ไม่ส่ง], @ชื่อเล่น และ @ทุกคน

- เตือน 4 เรื่อง:
  (1) โควตา LINE แพ็กเกจฟรีส่งได้ 300 ข้อความต่อเดือน และการส่งเข้ากลุ่ม 1 ครั้งนับตามจำนวนสมาชิกในกลุ่ม ให้คำนวณจากจำนวนสมาชิกกลุ่มของฉันว่าส่งได้ประมาณกี่ครั้งต่อเดือน
  (2) ห้ามลบไฟล์ _groups.json และ _sent.json ในโฟลเดอร์ Note from LINE
  (3) อย่าเชิญ OA นี้เข้ากลุ่มที่ไม่อยากให้ถูกจด และถ้าจดแชทที่มีลูกค้าหรือคนนอก ต้องแจ้งเขาว่ามีการบันทึกการสนทนา
  (4) อย่าเปลี่ยนสถานะแอปใน Google Cloud กลับเป็น Testing
- บันทึกสรุปทั้งหมดนี้เป็นไฟล์ "บันทึกบอทของฉัน.md" ในโฟลเดอร์โค้ด โดยไม่ใส่รหัสลับใด ๆ

# ถ้าติดปัญหา
- Verify ของ LINE ไม่ผ่าน: ตรวจว่า URL ลงท้ายด้วย /webhook, บอทขึ้นระบบแล้ว (เปิด https://<เว็บบอท>/ ได้) และ LINE_CHANNEL_SECRET ถูกต้อง (ถ้าผิด บอทจะตอบ 403)
- พิมพ์ในกลุ่มแล้วไม่มี log: ตรวจ Use webhook เปิดอยู่, OA ถูกเชิญเข้ากลุ่มสำเร็จจริง (ตั้งค่าอนุญาตเข้ากลุ่มแล้ว), ดู log ของบอทด้วย railway logs --service bot ว่ามีบรรทัด "Flushed" หรือ "Flush failed"
- /check ได้ drive.ok เป็น false:
  invalid_grant = สิทธิ์ Google หมดอายุหรือถูกยกเลิก ตรวจว่าแอปเป็น In production แล้วรัน google-login ใหม่และตั้ง GOOGLE_OAUTH_REFRESH_TOKEN ใหม่
  invalid_client = Client ID หรือ Client secret ผิด
  insufficient permissions = ตอนกดอนุญาตติ๊กไม่ครบ ให้รัน google-login ใหม่
  API has not been used / disabled = ยังไม่ได้ Enable Google Drive API ในโปรเจกต์ที่ถูกต้อง
- ไฟล์ไม่ถูกส่ง: ชื่อไฟล์ต้องขึ้นต้นด้วยวันที่วันนี้ตามเวลาไทยและตรงรูปแบบทุกตัวอักษร, ต้องเป็น Google Docs (ไม่ใช่ Word หรือไฟล์ข้อความ), ต้องอยู่ในโฟลเดอร์ "Comment from Dots" ที่บอทสร้าง, ชั่วโมงในชื่อไฟล์ต้องอยู่ในช่วงเวลาส่ง, ตั้ง TARGET_GROUP_ID แล้ว, และผ่านไปเกิน 1 นาทีหลังแก้ไฟล์ล่าสุด ดูสถานะที่ /check ช่อง readyDocsToday
- ส่งแล้ว LINE ตอบ 400 หรือ 403: OA ไม่ได้อยู่ในกลุ่มนั้นแล้ว หรือรหัสกลุ่มผิด ส่วน 429 = โควตาข้อความของเดือนนี้หมด
- ขึ้นระบบบน Railway ไม่ได้ หรือบอทขึ้นแล้วดับ: ดู railway logs --service bot บรรทัด "Missing required env var" บอกว่าตัวแปรไหนยังไม่ได้ตั้ง
````
