# AEIOU LINE ↔ Google Drive Bot

บอทตัวเล็กสำหรับ LINE Official Account 1 บัญชี ทำ 2 หน้าที่ในตัวเดียว

```
💬 กลุ่ม LINE ─▶ [A จด] ─▶ 📁 Note from LINE ─▶ 🧠 ผู้ช่วย AI อ่านและเขียน ─▶ 📁 Comment from Dots ─▶ [B ส่ง] ─▶ 💬 กลุ่ม LINE
```

- **A จด:** ทุกข้อความในห้องที่ OA อยู่ ถูกบันทึกเป็นไฟล์ข้อความใน Google Drive โฟลเดอร์ `Note from LINE` (1 โฟลเดอร์ต่อ 1 ห้อง, 1 ไฟล์ต่อเดือน)
- **B ส่ง:** Google Docs ที่ผู้ช่วย AI (เช่น Dots) เขียนไว้ในโฟลเดอร์ `Comment from Dots` ถูกส่งเข้ากลุ่ม LINE 1 กลุ่มที่กำหนด
- บอท**ไม่มี AI ข้างใน** ไม่คิดเอง ไม่ตอบเอง ส่วนที่คิดคือผู้ช่วย AI ที่อยู่ตรงกลาง

> สถานะ: ชุดสอนของ AEIOU Solution ทดสอบตรรกะของโค้ดในเครื่องแล้ว แต่ยังไม่ผ่านการซ้อมติดตั้งครบวงจรกับ LINE, Google และ Railway จริง

## ติดตั้ง

วิธีที่ออกแบบไว้คือให้ Claude Code ติดตั้งให้ โดยวาง prompt จาก [docs/install-prompt.md](docs/install-prompt.md) แล้วทำตามที่ Claude บอก จากนั้นตั้งผู้ช่วย AI ด้วย [docs/dots-prompt.md](docs/dots-prompt.md)

สิ่งที่ต้องมี: บัญชี LINE, บัญชี Google, บัญชี [Railway](https://railway.com) (มีค่าใช้จ่ายรายเดือน), Claude Code

## กติกาไฟล์ที่บอทจะส่ง (ส่วน B)

| กติกา | รายละเอียด |
|---|---|
| ชนิดไฟล์ | Google Docs ในโฟลเดอร์ `Comment from Dots` |
| ชื่อไฟล์พร้อมส่ง | `YYYY-MM-DD HH.MM — ชื่อเรื่อง` เช่น `2026-12-01 09.00 — สรุปเช้า` วันที่ต้องเป็นวันนี้ |
| ระหว่างเขียน | ตั้งชื่อขึ้นต้นด้วย `DRAFT` บอทจะไม่ส่ง จนกว่าจะเปลี่ยนชื่อเป็นรูปแบบพร้อมส่ง |
| เนื้อหา | ทั้งไฟล์คือข้อความที่จะส่ง |
| ไม่ต้องการส่ง | บรรทัดแรกเป็น `[ไม่ส่ง]` หรือเปลี่ยนชื่อกลับเป็น DRAFT หรือลบไฟล์ |
| แยกกล่องแชท | บรรทัดที่มีแค่ `---` ไม่เกิน 5 กล่องต่อไฟล์ |
| แท็กคน | `@ชื่อเล่น` ตามที่ตั้งใน `MENTIONS` และ `@ทุกคน` = @All |
| ส่งกี่ครั้ง | ไฟล์ละครั้งเดียว ถ้าต้องแก้ ให้สร้างไฟล์ใหม่ |
| เวลา | ตาม `SCHEDULE` ไฟล์ที่พ้นวันไปแล้วจะไม่ถูกส่งย้อนหลัง |

บอทเข้าไปดูโฟลเดอร์ทุก 1 นาที และรอ 1 นาทีหลังไฟล์ถูกแก้ล่าสุดก่อนส่ง

## ค่าที่ต้องตั้ง (Environment variables)

| ชื่อ | จำเป็น | คืออะไร |
|---|---|---|
| `LINE_CHANNEL_ID` | ✅ | จาก LINE Developers → Basic settings |
| `LINE_CHANNEL_SECRET` | ✅ | จาก LINE Developers → Basic settings |
| `GOOGLE_OAUTH_CLIENT_ID` | ✅ | OAuth client แบบ Desktop app จาก Google Cloud |
| `GOOGLE_OAUTH_CLIENT_SECRET` | ✅ | คู่กับ Client ID |
| `GOOGLE_OAUTH_REFRESH_TOKEN` | ✅ | ได้จาก `node scripts/google-login.js <client_id> <client_secret>` |
| `ADMIN_KEY` | ✅ | รหัสสุ่มยาว ๆ สำหรับหน้าตรวจสอบ |
| `TARGET_GROUP_ID` | | รหัสกลุ่มที่จะส่งเข้า ถ้ายังไม่ตั้ง บอทจะจดอย่างเดียว ยังไม่ส่ง |
| `SCHEDULE` | | ค่าเริ่มต้น `0-6=7-20` = ทุกวัน 07:00–20:59 ตัวอย่าง `1-5=9-18` = จันทร์–ศุกร์ 09:00–18:59 (0 = อาทิตย์) |
| `MENTIONS` | | JSON ชื่อเล่น → รหัสผู้ใช้ LINE เช่น `{"มะลิ":"Uxxxx"}` |
| `NOTE_FOLDER_NAME` / `COMMENT_FOLDER_NAME` | | ชื่อโฟลเดอร์ตอนสร้างครั้งแรก |

## หน้าตรวจสอบ

ใส่รหัสใน header `X-Admin-Key` หรือ `?key=`

- `GET /check` ดูว่า LINE และ Drive เชื่อมได้ไหม โฟลเดอร์อยู่ที่ไหน วันนี้มีไฟล์พร้อมส่งอะไรบ้าง โควตาเหลือเท่าไร
- `GET /groups` รายชื่อห้องที่บอทจดอยู่ พร้อมรหัสกลุ่มและรหัสผู้ใช้ของคนที่เคยพิมพ์ (ใช้ตั้ง `TARGET_GROUP_ID` และ `MENTIONS`)
- `GET /run` สั่งส่งตอนนี้โดยไม่สนตารางเวลา (สำหรับทดสอบ)

## ข้อควรรู้

- **โฟลเดอร์ทั้งสอง บอทสร้างให้เองตอนเริ่มทำงาน** ย้ายหรือเปลี่ยนชื่อภายหลังได้ ห้ามลบไฟล์ `_groups.json` และ `_sent.json`
- **สิทธิ์ Google:** บอทอ่านไฟล์ใน Drive ได้ แต่แก้หรือลบได้เฉพาะไฟล์ที่บอทสร้างเอง แนะนำใช้บัญชี Google แยกสำหรับระบบนี้
- **โควตา LINE:** ส่งเข้ากลุ่ม 1 ครั้ง นับตามจำนวนสมาชิกในกลุ่ม แพ็กเกจฟรีมี 300 ข้อความต่อเดือน
- **ห้ามเพิ่ม replica** ให้รันตัวเดียวเท่านั้น
- **ความเป็นส่วนตัว:** ถ้าจดแชทที่มีลูกค้าหรือบุคคลภายนอก ต้องแจ้งให้ทราบว่ามีการบันทึกการสนทนา (PDPA)
